Los CSV de esta carpeta son referencias para verificar los resultados recalculados desde los datos. `SHA256SUMS` comprueba su integridad; el script 04 verifica los nueve descriptivos y el 06 las tres tablas de menciones. Se exige igualdad de etiquetas, faltantes y conteos; los demás valores admiten una diferencia máxima de `1e-10 × (1 + abs(referencia))`. Las referencias no se utilizan para calcular los resultados.
